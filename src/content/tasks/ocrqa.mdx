## Impresso Pipelines library 

### Impresso pipelines:

[impresso_pipelines.ocrqa](https://pypi.org/project/impresso_pipelines/)

```python
pip install impresso_pipelines[ocrqa]

from impresso_pipelines.ocrqa import OCRQAPipeline

# Initialize pipeline (downloads model on first use)
ocrqa_pipeline = OCRQAPipeline()

# Classify a single text
text = "Ein kleiner Hund wqeg Max lebte in einem ruhigen Dorf."
result = ocrqa_pipeline(text)
result
```
