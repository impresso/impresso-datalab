Although researchers have already addressed this question, recently by using computational methods to assess the influence of news agencies at present, large-scale studies on the role of news agencies in the past continue to be rare. ## Impresso Pipelines library

### Impresso pipelines:

[impresso_pipelines.newsagencies](https://pypi.org/project/impresso-pipelines/)

```python
pip install impresso-pipelines

from impresso_pipelines.newsagencies import NewsAgenciesPipeline

# Initialize the pipeline
pipeline = NewsAgenciesPipeline()

de_text = "Wie das Wolffs Telegraphisches Bureau (Wolff) gestern in einer abendlichen Meldung verlautbarte, trat der Haushaltsausschuss „unter beträchtlichem Andrang der Presse“ zusammen."

# Extract entities
result = pipeline(de_text)
print(result)
```
