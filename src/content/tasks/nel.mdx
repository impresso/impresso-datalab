## Impresso Python library

### Impresso Py tool:

[resources.tools.ToolsResource.nel](https://impresso.readthedocs.io/en/latest/resources/#impresso.resources.tools.ToolsResource.ner)

```python
text = "[START] Jean-Baptiste Nicolas Robert Schuman [END] (29 June 1886 – 4 September 1963) was a Luxembourg-born French statesman."
# Link named entities to wikidata 
result = impresso.tools.nel(text=text)
result.df  # View entities as DataFrame
```
